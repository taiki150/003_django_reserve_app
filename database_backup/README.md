# データベースバックアップディレクトリ

このディレクトリは、DBeaverで管理するためのデータベースファイルのコピーを保存するために使用します。

## 使用方法

1. 既存のデータベースファイルをこのディレクトリにコピー：
   ```bash
   cp ../user/login_view/db.sqlite3 ./db.sqlite3
   ```

2. DBeaverでこのファイルを開く

3. 必要に応じて、このディレクトリのファイルを元の場所に戻すことができます

## 注意

- このディレクトリのファイルはバックアップ/参照用です
- 実際のDjangoアプリケーションは `../user/login_view/db.sqlite3` を使用します
